Manim_Publisher – Privacy Policy

Effective date: 24 November 2026

Manim_Publisher is a private, internal tool. It uploads math and physics videos to a single YouTube channel (hourlymath), and only its owner uses it. No one else can sign in to it or use it.

Use of YouTube API Services

Manim_Publisher uses YouTube API Services. By using it you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

What data the tool accesses

When the owner signs in with Google, the tool asks for two permissions:

  • youtube.upload: to upload videos to the owner's channel.
  • youtube.force-ssl: to add captions to those videos and add them to the owner's playlists.

The tool reads back only what YouTube returns for its own uploads (the video ID and link) and the channel name, to confirm the right channel is signed in.

How data is stored

  • The Google sign-in token is stored only on the owner's computer, in a private file. It is never sent anywhere except to Google's servers.
  • A local log records which videos were uploaded (video ID, title, upload time). It stays on the owner's computer.
  • The tool has no server, database, analytics, cookies or advertising.

Sharing

The tool does not share, sell or transfer any data to anyone. Data goes only between the owner's computer and Google/YouTube.

Revoking access and deleting data

You can remove the tool's access at any time in your Google account security settings. Deleting the local token file and upload log removes everything the tool stores.

Changes

If this policy changes, the effective date above will be updated.
